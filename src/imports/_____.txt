
生词提取器 - 产品功能说明文档

一、产品概述

产品名称：生词提取器
产品定位：Chrome 浏览器扩展（Manifest V3），一键提取网页英文单词，用于词汇背诵
目标用户：使用「不背单词」等背词 APP 的学习者
核心价值：从任意网页快速提取英文单词，自动过滤已学词汇，支持批量导入背词 APP

---
二、核心功能模块

1. 单词提取功能（popup.js）

功能描述：从当前浏览的网页中智能提取英文单词

具体能力：

1. 智能文本提取
  - 使用 TreeWalker 遍历页面所有可见文本节点
  - 自动排除 script、style、noscript、iframe、svg、path、code、pre 等非内容标签
  - 过滤隐藏元素（display:none、visibility:hidden）
  - 提取页面完整可见文本内容
2. 单词匹配规则
  - 正则匹配：/[a-zA-Z]{3,}/g（3 字符以上的英文单词）
  - 自动去重（使用 Set 数据结构）
  - 自动转小写统一格式
  - 按字母顺序排序输出
3. 已收录词汇过滤
  - 提取时自动排除用户已收录的词汇
  - 只显示未学习的新单词
  - 显示过滤统计：新词数量 + 已过滤数量
4. 提取结果展示
  - 显示单词总数统计
  - 预览前 100 个单词（超出部分省略）
  - 每个单词以标签形式展示
5. 页面兼容性提示
  - 自动检测 chrome://、chrome-extension:// 等特殊页面
  - 特殊页面显示「此页面不支持提取」提示
  - 连接失败时显示刷新重试提示

---
2. 导出功能（popup.js）

功能描述：将提取的单词导出用于背词 APP 导入

具体能力：

1. 复制到剪贴板
  - 一键复制全部单词到剪贴板
  - 格式：每行一个单词（换行分隔）
  - 复制成功后按钮显示「已复制 ✓」反馈（1.5秒）
  - 自动收录：复制时自动将单词加入「已收录词汇」
2. 下载 TXT 文件
  - 下载为纯文本文件
  - 文件名格式：words_YYYY-MM-DD.txt（带日期）
  - 内容格式：每行一个单词
  - 自动收录：下载时自动将单词加入「已收录词汇」

---
3. 已收录词汇管理

功能描述：管理用户已学习的词汇库，用于提取时自动过滤

具体能力：

1. 词汇存储
  - 使用 chrome.storage.local 本地持久化存储
  - 存储格式：数组（自动转 Set 去重）
  - 存储键名：collectedVocabulary
2. CRUD 操作
  - 添加单个词汇：输入框 + 添加按钮，支持 Enter 快捷键
  - 批量添加词汇：接收单词数组，返回新增数量
  - 删除单个词汇：词汇列表中每个单词带删除按钮（×）
  - 清空全部词汇：带二次确认对话框（不可恢复警告）
  - 词汇总数统计：实时显示当前词汇数量
3. 导入功能

3. 手动输入导入：
  - 文本框粘贴单词列表
  - 支持多种分隔符：换行、空格、逗号、分号、制表符
  - 自动解析并过滤无效格式
  - 显示导入成功数量

文件导入：
  - 支持上传 .txt 文件
  - 自动读取文件内容并解析
  - 支持多种分隔符格式
  - 显示导入成功数量
4. 导出备份
  - 导出为 TXT 文件
  - 文件名格式：collected_vocabulary_YYYY-MM-DD.txt
  - 内容按字母顺序排序
  - 用于数据备份或迁移
5. 备份提醒
  - 当词汇数 ≥ 100 时显示备份提醒
  - 提示内容：「建议定期导出备份，卸载扩展后数据将丢失」
6. 单词格式校验
  - 标准化规则：trim + toLowerCase
  - 格式要求：^[a-z]{3,}$（3+ 字母纯英文）
  - 无效格式显示错误提示
  - 导入时自动过滤无效单词并记录示例

4. 用户界面功能

主界面（popup.html）：

- 标题 + 副标题介绍
- 「提取单词」按钮（主操作）
- 统计信息动态显示
- 单词预览区域（前 100 个）
- 复制全部 + 下载 TXT 按钮
- 底部说明 + 管理页面入口链接

管理界面（options.html）：

- 标题 + 副标题说明用途
- 词汇总数统计
- 备份提醒（条件显示）
- 添加词汇区域（输入框 + 按钮）
- 导入词汇区域（文本框 + 文件上传）
- 词汇列表展示（标签式 + 删除按钮）
- 导出备份 + 清空全部按钮

消息提示系统：

- 成功/错误/信息三种类型
- 自动消失（默认 2秒，特殊 3秒）
- 类型样式区分（颜色）

5. 扩展配置

基本信息：

- 扩展名称：生词提取器
- 版本：1.0.0
- 描述：一键提取网页英文单词，用于词汇背诵

权限声明：

- activeTab：访问当前标签页
- scripting：动态注入脚本执行提取
- storage：存储已收录词汇

页面配置：

- popup.html：主界面弹窗
- options.html：管理页面（作为 options_page）

图标：

- 16×16、48×48、128×128 三种尺寸
- 存储路径：icons/iconXX.png

---
三、功能流程说明

单词提取流程

用户点击「提取单词」
  → 检查页面兼容性
  → 注入脚本到页面
  → TreeWalker 遍历文本节点
  → 正则匹配英文单词
  → 去重 + 小写 + 排序
  → 加载已收录词汇
  → 过滤已收录单词
  → 显示新词列表
  → 用户选择导出方式
  → 自动收录到词汇库

词汇管理流程

用户进入管理页面
  → 加载词汇库
  → 显示统计 + 列表
  → 用户操作（添加/导入/删除/清空）
  → 更新存储
  → 刷新显示

---
四、技术特性

1. 无构建系统：源码直接作为扩展运行，无需编译打包
2. Manifest V3：符合最新 Chrome 扩展标准
3. 动态脚本注入：使用 chrome.scripting API，无需 content script 常驻
4. 本地存储：数据存储在浏览器本地，卸载扩展后数据丢失
5. 智能过滤：已收录词汇自动过滤，避免重复学习
6. 批量操作：支持批量导入、批量收录，提高效率

---
五、使用场景

1. 阅读英文文章：一键提取文章所有生词
2. 学习网页内容：从教程、文档提取专业词汇
3. 批量导入背词 APP：导出后导入「不背单词」等应用
4. 词汇积累管理：长期维护已学习词汇库
5. 数据备份迁移：导出备份防止数据丢失
